# 자기소개서

##### 현대오토에버에 지원한 동기를 기술하십시오(이직사유 포함, 최대 500자)

​데이터 엔지니어로 성장하기 위해서는 다양한 데이터를 다루는 경험과 소프트웨어 개발 역량이 필요하다고 생각합니다. 첫 커리어를 플랫폼 엔지니어로 시작하여 1금융 은행의 데이터 플랫폼을 전담으로 구축한 경험과, 데이터 불모지인 유통업계의 데이터 니즈에 맞춰 검색, 추천 서비스까지 개발해 보았지만, 아직 제가 경험하지 못한것이 있다면 대용량 데이터를 다뤄보는것입니다. 데이터의 힘을 믿기에, 데이터가 흐르는 곳은 엔지니어링, 개발 구분 하지 않고 조직이 직면한 문제를 해결하기 위해 최선을 다합니다. 글로벌 최고의 모빌리티 소프트웨어를 개발하고 대량의 데이터를 처리하며 데이터 플랫폼을 개발하고 있는 현대오토에버에서 데이터 엔지니어의 꿈을 실현할 수 있을 것으로 생각하여 지원하였습니다. 저는 데이터 중심의 비즈니스 환경에서 더 깊은 이해를 바탕으로 역량을 키우고 싶어 하며, 현대오토에버가 이러한 기회를 제공할 것으로 기대하고있습니다.


##### 입사 후 희망 업무를 본인의 강점을 근거로 기술하여 주시기 바랍니다. (채용 공고상 담당업무 참고, 최대 1000자)

​저의 강점은 Data Platform 운영을 위해 필요한 업무 역량 폭이 넓다는 것입니다. Data를 원활하게 흘러가게 하기위해 기술적 탐구를 멈추지 않고 끊임 없이 성장에 목말라있었습니다. 제 강점을 근거로하여 인증 중고차 분석 파이프라인 및 서비스 관리 업무를 맡게 된다면, 하기 업무들을 맡고싶습니다.

1. 인증 중고차 시세 제공 서비스 개발/운영:
	추천 시스템 개발을 통해 파이프라인 설계부터 데이터 서빙까지 고객의 니즈에 따라 추천 데이터를 제공한 경험이 있습니다. R&R상 Data Engineering 파트만 수행해도 문제가 없었지만, 추천 데이터를 가장 잘 아는 엔지니어였기에 Spring 기반 RestAPI를 개발하여 데이터를 직접 고객에게 Serving 했었습니다. 인증 중고차 시세 분석 제공을 위한 RestAPI 서비스도 비슷한 Case라고 생각하고 분석을 위한 데이터를 안정적으로 운영하려면 Backend, Data Engineering 역량이 둘다 필요하다고 생각합니다.
    
2. 데이터 파이프라인 개발/운영:  
    데이터 파이프라인의 설계부터 구축, 모니터링, 문제 해결 및 성능 튜닝까지의 전 과정을 경험했습니다. DW 구축 프로젝트에서는 전사적으로 사용할 데이터 웨어하우스를 구축하고 이를 기반으로 Redash를 활용한 지표 통계 대시보드를 개발했습니다. Data-Driven한 플랫폼 구축에 관심이 많아 분석가들을 위해 데이터 마트 또한 자발적으로 운영했었습니다. 전사적으로 Airflow DAG 개발 형식을 맞추고 싶어 Dag Factory, Dag CI/CD 프로젝트를 진행했으며 전사적으로 Data-Driven한 결정을 내릴수 있도록 노력했습니다. 따라서 인증 중고차 분석을 위한 데이터 파이프라인을 구축하고 안정적으로 운영하는 데에 적합한 인재라고 생각하여 서비스를 담당해보고싶습니다.
