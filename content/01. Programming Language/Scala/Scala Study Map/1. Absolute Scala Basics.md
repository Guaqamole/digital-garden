# Expressions
- scala uses if statement as expression as other languages use them as instruction (todo)
- **scala forces to use everything as expression**
- NEVER WRITE IMPERITIVE CODE in scala (means do not use for loops like used in java or python.)
## Instruction vs Expression
### instruction (do)
- telling comptuter to do.

### expression (value)
- functional programming uses expression

if statement as expression
```scala
object Expressions extends App {  
  val aCondition = true  
  val aConditionValue = if(aCondition) 5 else 3  
  println(aConditionValue)  
}
```

### imperitive style (dont do this in scala)
```python
val i = 0  
while (i < 10) {  
  println(i)  
  i += 1  
}
```

# Functions
```scala
def aFunction(a: String, b: Int): String = {  
  a + " " + b // implementation is single line expression  
}  
  
println(aFunction("hello" + 3)) // calling a function is still expression
```
## Loops as Function
> [!note]  
> in scala recursive function is normally used instead of loops

```scala
def aRepeatedFunction(aString: String, n: Int): String = {  
  if (n == 1) aString  
  else aString + aRepeatedFunction(aString, n-1)  
}  
println(aRepeatedFunction("hello", 3))
```

## Return type
### No Return Type
- best practice: always mention return type
- always mention return type in loops
```scala
// No Error  
def aFunction(a: String, b: Int)  = {  
  a + " " + b  
}  
  
// Error  
def aRepeatedFunction(aString: String, n: Int) = {  
  if (n == 1) aString  
  else aString + aRepeatedFunction(aString, n-1)  
}
```

### Unit return type
```scala
def aFunctionWithSideEffects(aString: String): Unit = println(aString)
```
