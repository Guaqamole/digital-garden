## Chat vs Composer
1. `Ctrl` + `K` for in-file code generation and `quick questions`
2. `Ctrl` + `L` (Chat) to open up an AI chat panel in the sidebar
3. `Ctrl` + `I` (Composer) to create and edit code across multiple files

General, Idea가 필요할때는 단순히 chat을 사용하면될듯. 전체적인 코드 변경, 개선점을 apply하고 싶으면 Composer에게 질문.
