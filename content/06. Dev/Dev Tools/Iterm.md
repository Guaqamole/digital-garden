## Panes
### Split Pane Navigation
```python
Cmd + ] , Cmd + [
```

### Split Pane Vertical
```python
Cmd + D
```


### Split PaneHorizontal
```python
Shift + Cmd + D
```


### Broadcast inputs to ALL panes
- 여러 서버에서 한꺼번에 작업하기 좋음
```python
Shift + Cmd + I
```


### Broadcast inputs to current pane
```python
Option + Shift + Cmd + I
```
