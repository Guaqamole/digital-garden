## 코드 생산성을 개선하는 방법
1. 코드 가독성
	1. 개발 규모가 커질수록 코드를 이해하는 시간이 비례적으로 늘어나기 때문에 가독성을 높여야한다.
	2. 필요하지 않을때
		1. 거의 읽히지 않는 일회성 코드
	3. 언제 가독성에 투자하나
		1. 코드를 읽는 시간, 코드를 작성하는 시간중 어느쪽 비중이 높은지 판단
		2. 코드를 읽는시간이란
			1. 다른 개발자에게 코드를 설명하는시간
			2. 코드를 작성하는도중 다른 코드를 참고하는 시간
			3. 코드를 리뷰하는 시간
