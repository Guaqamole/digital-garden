## 검색엔진에 대한 이해
검색엔진의 역할 - 대용량 문서에서 쿼리에 매칭되는 문서를 빠르게 찾기위해 여러가지 기술을 사용
- 그중 가장 핵심은 역색인 (Inverted Index) 자료구조 ([[Elasticsearch#In-memory buffer]])
- 색인한다: 역색인을 만든다
- 검색한다: 역색인 구조에서 쿼리텀이 일치하는 문서를 찾는것

### Indexing
1. 형태소 분석
	1. 형태소 분석을 통해 문서에서 의미있는 텀들을 골라낼수 있다
2. 텀들을 분류하여 문서별로 텀 리스트 작성
	1. 리스트들을 합친후, 텀들이 어느 문서에서 나왔는지 나열
	2. 완성된 결과를 역색인이라고 부름
	3. 검색에 활용되는 역색인
3. 사용자 질의어 인입
	1. 질의어가 인입되면 색인 단계처럼 형태소 분석 진행.
	2. 예) “윤미래 아들” → “윤미래”, “아들”
4. 윤미래, 아들이 모두 존재하는 문서를 찾기위해, document lsit에서 각 텀이 포함된 문서를 가져온다.
	1. 윤미래 → 문서1, 문서2
	2. 아들 → 문서2
5. 검색이 “잘” 된다 의 정의는 문서간 유사도, 및 랭킹 시스템에 의해서 결정됨.
	1. 하지만 검색 결과는 정답이란게 없기 떄문에
	2. 사용자의 ‘개인적인’ 의도에 맞게 검색이되어야함.
	3. 즉, 데이터를 기반으로 개인화가 필요함.


### Inverted vs Vertical
- 기존 검색: 선별 → 평가 → 정렬 → 반환
- 벡터 유사도 검색: 평가 → 정렬 → 반환
