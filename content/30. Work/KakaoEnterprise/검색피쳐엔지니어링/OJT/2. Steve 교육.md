## straw (json format)
- primary index → key
- secondary index 지원
	- gsid & dsid (많이 쓰니 필수로 설정) → secondary index, article id
	- partition_key
	- 주로 조회하는 key 로 index 걸음
- 두가지 데이터가있음
	- event (history) data
	- object data
- straw 구조 cluster (server) → box (database) → type (table)
	- box ex) tistory databse
	- type ex) tistory, daum blog, 
- straw안에 event record가 갱신되는 방법
	- box 단위로 설정할 수 도 있고
	- type으로 설정 할 수 도 있음
- \_connects: 같은 클러스터면 join 가능


## Rebuild vs ReIndex
- rebuild: 기존 검색 결과에서 garbage 데이터 삭제하는 작업
- reindex: 원본 데이터를 가지고와서 다시 넣음
- 정적색인: 데이터가 적을때 바꾸지 않고 그대로 넣음

## Dynamic vs Static index

- static: init → index (과거 데이터가 없음)
