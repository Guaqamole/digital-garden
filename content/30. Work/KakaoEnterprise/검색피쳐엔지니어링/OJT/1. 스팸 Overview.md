## Spam Concepts
- Hammer(total), Filter(filter), Butcher(api), Ventilator(collector), Tenderizer(운영툴)
    - Hammer → palu
    - tenderizer → dungeon,xdev → labelcraft, querycraft
    - sven, dsat, wasp ...
- 스팸이란?
	- 영리 목적 & 검색 시스템의 취약점을 이용하여 검색 결과 상위에 노출되도록 인위적으로 검색 결과를 조작하고 품질을 저해시키는 게시물
	- 정보통신망법, 저작권법 및 이와 연관된 법률에 위배되는 일체의 게시물로 이용자가 웹서비스상의 정보를 활용하는 과정에서, 정상적인 정보 활용에 방해나 위해를 주는 유해게시물까지 통칭
- 스팸 판단의 대전제 (스팸의 기준)
	- 의도적으로 작성되었는가?
	    - 검색엔진 상위에 랭크되기 위한 의도
	    - 유저를 속이려는(fake, fishing 등) 의도
	- 기계적으로 작성되었는가?
	    - 문서의 작성일시기준으로 짧은 시간내에 대량의 문서를 포스팅
	    - 꾸준하게 하루에 일정건수씩(또는 일정시간에) 포스팅
	    - 문장의 흐름이 자연스럽지 못하고 단어의 나열등을 이용한 포스팅
	- 검색품질에 도움이 되는가?
	    - 해당문서 검색 노출 시 (다음)검색 품질이 좋아보일지 고민
	    - well-made 된 문서인지?
	- 사용자에게 도움이 되는가?
	    - 해당문서가 검색 유저에게 충분한 정보를 제공하고 있는가?
	    - 악성코드등의 유포로 피해를 주고 있지 않은가?
- 예시
	- 제목/본문 키워드 어뷰징 : 본문 내용과 연관성 유무 관계없이
	- 블로그 내 대부분 문서가 유사한 내용
	- 의미없는 문서
	- 이슈키워드 포함 문서를 대량 포스팅
	- 본문 내 정보성 text 비율
	- 의도적으로 댓글을 대량 작성
	- 무분별한 짜깁기

### Hammer Level
- Ham: 나가도 되는 문서
- Spam
	- hiding keywords (white / tiny fonts)
		- 블로그 내 대부분의 문서에 Keywords hiding (white&tiny font)을 시도한 경우
		- 블로그의 특정 문서만 Keywords hiding (white&tiny font)을 시도하면서 Gray-Feature 가 포함된 경우
	- keyword stuffing
		- repetition
			- 본문내용과 관련없는 키워드(또는 문장, 링크, 이미지, 동영상)가 대량으로 삽입된 경우
			- 본문내용과 관련있어도 과도하게 삽입되면
		- dumping
		- weaving
			- 문장 중간에 의도적으로 키워드를 삽입하는 경우
			- 주로 복사된 문장사이에 삽입된다
		- word salad
	- abusive contents
		- 성인
		- 불법
		- 저작권
	- redirect
		- 크롤(색인)된 내용과 링크로 이동되는 페이지 내용이 다른경우
- Gray
	- 정의: 스팸기준에는 미치지 못하지만 저품질의 문서들로 검색결과에 영향을 미치는 블로그
	- 반복: 본문내용과 관련있는 키워드(또는 문장, 링크, 이미지, 동영상)가 과도하지 않게 반복되는 경우
	- 블로그 내 대부분의 문서가 동일한 링크(연락처,이메일, 홈페이지 등)를 포함하고 있는 경우

- 메타 무시 0 → article만 나간다.
