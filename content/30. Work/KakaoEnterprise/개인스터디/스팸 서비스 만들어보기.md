## How
1. 어떻게 개발 환경 만들수 있는지 알아보기… (서버, DKOS, palu)
1. 환경 셋업
2. 각 레이어별로 데이터 넣어보기
	1. kafka → flink → hdfs: 동적 필터링을 한 뒤 feature를 hdfs에 저장
	2. kafka → flink → straw: 동적 필터링을 한 뒤 summary를 straw에 저장
	3. hdfs → flink → hdfs: 재처리를 한 뒤 feature를 hdfs에 저장
	4. hdfs → flink → straw: 재처리를 한 뒤 summary를 straw에 저장
3. 각 데이터 흐름대로 코드 실행해보기
4. 코드 고쳐보기
