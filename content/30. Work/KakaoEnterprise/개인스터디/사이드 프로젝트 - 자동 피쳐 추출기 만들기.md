## 기능
Input: 스팸으로 분류된 특정 문서 모음집 
Output: 중요한 피쳐들 추출 (퍼센티지로)

1. EDA → 전체 모수 파악 (컬럼 별로 특징 파악)
2. 컬럼 Norm. (예: 텍스트면 벡터로 변경)
3. Correlation Analysis → 상관 분석 → 피처 추출

## 단계
### **Step 1: 데이터 준비**
- 사용자가 그룹화한 문서를 입력으로 받습니다.
- 각 문서 그룹에서 피처를 추출하고 전처리:
    - 데이터 타입별 처리: Numeric, Categorical, Boolean, Text.
### **Step 2: 피처 중요도 도출**
- 그룹별로 중요한 피처를 추출하기 위한 모델을 설계:
    1. 지도 학습 모델 (예: Random Forest, XGBoost)을 사용해 **피처 중요도(feature_importances_)**를 확인.
    2. SHAP이나 LIME 같은 설명 기법으로 피처의 중요도를 시각적으로 확인.

### **Step 3: 출력**
- 주요 피처를 중요도 점수와 함께 출력.
- 사용자가 확인할 수 있도록 상위 중요 피처 리스트와 간단한 시각화를 제공.

### Step 4: 평가설계
- **피처 중요도 도출 결과의 신뢰성**과 **실제 적용 가능성** 평가.
- 중요한 피처를 기반으로 작성된 쿼리가 실제로 스팸 문서를 효과적으로 필터링하는지 검증. → qc

- **Feature Importance 평가**:
    - 주요 피처가 문서 필터링에 얼마나 기여했는지.
    - `Feature Attribution` 기반 지표(SHAP, LIME 등) 사용 가능.
- **스팸 필터링 성능 평가**:
    - 도출된 피처를 기반으로 작성한 쿼리의 **정확도(Accuracy)**, **정밀도(Precision)**, **재현율(Recall)** 측정.
#### 방법
##### a. 주요 피처 신뢰성 평가
- **방법 1: 기존 피처 기반 쿼리와 비교**:
    - 이전에 수작업으로 작성한 스팸 필터링 쿼리가 있다면, 해당 쿼리에 사용된 피처와 도출된 주요 피처 리스트를 비교.
    - **Cosine Similarity**나 **Jaccard Similarity**를 사용하여 두 리스트 간 유사도를 수치화.
- **방법 2: SHAP 또는 LIME로 피처 중요도 시각화**:
    - 주요 피처가 모델의 예측 결과에 미친 영향을 시각적으로 확인.
    - 예시: SHAP Summary Plot, Force Plot 등.
##### **b. 쿼리 기반 필터링 성능 평가**
- 도출된 피처를 기반으로 작성된 쿼리를 스팸 문서 데이터에 적용.
- 쿼리의 필터링 결과를 실제 라벨(스팸/정상)과 비교하여 **평가 지표** 계산:
    - **Precision**: 쿼리가 스팸이라고 판단한 문서 중 실제 스팸 문서의 비율.
    - **Recall**: 실제 스팸 문서 중 쿼리가 정확히 스팸으로 필터링한 비율.
    - **F1 Score**: Precision과 Recall의 조화 평균.
