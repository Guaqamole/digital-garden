- 필터쿼리

```sql
select *
from dl_ext.dl_ext_shop_biz_info
where status = 'valid'
and bizno_net.name is not null
and sbiz.name is not null
and sbiz.update_dt is not null
```

- nested column 별 update_dt
	- 존재시 검색을 한번 한 데이터
	- 만약 update_dt null이면, 검색(크롤링) 안한 데이터
	- update_dt is not null
		- 뒤 데이터 전부다 널이면 못찾은애들
		- 데이터 존재시 찾은 경우
- 필터 순서 sbiz cate > bizno_net cate
