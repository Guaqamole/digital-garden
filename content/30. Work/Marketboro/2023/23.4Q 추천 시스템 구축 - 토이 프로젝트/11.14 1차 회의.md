# user
- 학습시 전체
- 추론시 조정필요
- cmt_shop
	- shop_id
	- birth → age
	- gender → 1:M / 2:F
```sql
SELECT   
shop_id as USER_ID,  
   IFNULL(EXTRACT(year from current_date()) - EXTRACT(year from birth),0) as AGE,  
   IFNULL(gender,0) AS GENDER  
FROM gred.cmt_shop
WHERE use_yn='y'
```

# item
- 학습시 전체
- 추론시 조정 필요
- cmt_goods
	- goods_id
	- category_search_id
- cmt_goods_category
	- category_id
	- category_name

```sql
SELECT
	goods_id as ITEM_ID,
    price as PRICE,
	SUBSTRING_INDEX(category_search_id, ',', 1) as CATEGORY_L1
FROM gred.cmt_goods
WHERE price != 0
AND use_yn = 'y'
AND del_yn = 'n'
```

### Checking…
```sql
SELECT  
    cg.goods_id as ITEM_ID,  
    substring_index(cg.category_search_id, ',', 1) as category_id,  
    cc.category_name  
FROM cmt_goods as cg  
LEFT JOIN cmt_goods_category as cc ON substring_index(cg.category_search_id, ',', 1) = cc.category_id
```

# interaction
- 조정할수있게 고려
### purchase_df
- EVENT_TYPE = ‘purchase’
```sql
SELECT
	cog.shop_id as USER_ID,
	cog.goods_id as ITEM_ID,
	UNIX_TIMESTAMP(cog.regist_dt) as TIMESTAMP,
	'purchase' as EVENT_TYPE
FROM cmt_order_master com
INNER JOIN cmt_order_goods cog
ON com.order_master_id = cog.order_master_id
WHERE cog.order_status = 'OS002'
AND cog.order_claim_status NOT IN ('OCS002', 'OCS005')
AND cog.qty != cog.return_qty
AND cog.use_yn = 'y'
--AND com.pay_dt >= '2019-01-01' AND com.pay_dt <= '2023-12-31'
```

### cart_df
- EVENT_TYPE = ‘cart’
```sql
SELECT 
    shop_id as USER_ID, 
    goods_id as ITEM_ID,  
    UNIX_TIMESTAMP(update_dt) as TIMESTAMP, 
    'cart' as EVENT_TYPE
FROM gred.cmt_cart
WHERE login_type='shop'
AND use_yn = 'y'
```

### bookmark_df
- EVENT_TYPE = ‘bookmark’
```sql
SELECT  
    shop_id as USER_ID,  
    goods_id as ITEM_ID,  
    UNIX_TIMESTAMP(update_dt) as TIMESTAMP,  
    'bookmark' as EVENT_TYPE  
FROM gred.cmt_bookmark  
WHERE use_yn='y'
AND goods_id != 0
```
