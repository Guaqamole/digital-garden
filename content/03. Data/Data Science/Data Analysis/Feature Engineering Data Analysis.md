**데이터 분석의 목적은 크게 두 가지 흐름으로 나뉠 수 있어**:

---
### ✅ 1. **모델 구축을 위한 분석 (Feature Engineering 목적)**

> "이 데이터를 어떻게 **수치화하고 모델이 이해할 수 있게 만들 것인가?**”
### 예시:
- **AI vs Human 글 분류** → 단어 다양성, 문장 길이, 문법 오류 수 등 피처 설계
- **고객 이탈 예측 모델** → 최근 접속 빈도, 결제 이력, CS 이력 등을 피처로 만듦
- **주가 예측 모델** → 이동평균선, 거래량 변화율, RSI, MACD 등 수학적 피처 생성    

👉 이 경우 분석은 “데이터로부터 좋은 입력값(X)을 만들기 위한 준비 작업”이야.  
여기서의 분석은 보통:
- 패턴 탐색 (EDA)
- 통계 요약
- 상관관계 파악
- 피처 선택 / 변형  
    등으로 이어져서 **모델의 성능 향상**이라는 뚜렷한 목적이 있음.

---
### ✅ 2. **현상 이해를 위한 분석 (설명적 분석, Exploratory 목적)*
> "지금 무슨 일이 벌어지고 있고, 왜 그런지 이해하고 싶다.”
### 예시
- A 서비스에서 고객 이탈률이 급등했다 → 어떤 페이지에서 주로 나가나?
- 제품 카테고리별 매출을 비교해서 → 마케팅 예산을 어디에 더 배분할지 결정
- 신규 기능 도입 후 → 고객 만족도가 어떻게 바뀌었는지 확인

👉 이 경우 분석은 모델링보다는 **인사이트 도출, 현상 설명, 전략 제시**에 초점이 있어.  
주로 사용하는 도구는
- 시각화 (히트맵, 시계열, 군집도 등)
- 비율 비교, 요약 통계
- 가설 검정 (이 차이가 우연이 아닌지)
- 회귀분석 (원인 탐색용)  
    등이야.

---

### ✅ 3. 구체적 분석 흐름 (실무 수준 단계별 프로세스)

| 단계         | 설명                        | 도구/기법                                  |
| ---------- | ------------------------- | -------------------------------------- |
| **Step 1** | 데이터 수집 (AI 텍스트 vs 사람 텍스트) | 수동 수집, API 활용, 웹스크래핑                   |
| Step 1-2   | 데이터 타입 파악                 | 시계열, 범주형, 수치형, 텍스트, 이미지등               |
| **Step 2** | 전처리                       | 소문자화, 특수문자 제거, 문장 분리, 토큰화              |
| **Step 3** | **텍스트 통계 피처 추출**          | 문장 길이, 고유단어비율, 문법 패턴, 품사 비율            |
| **Step 4** | **언어학 기반 피처**             | 어휘 다양성 (Type-Token Ratio), 문장 구조 패턴    |
| **Step 5** | **TF-IDF / BERT 임베딩**     | 고차원 의미 피처 생성                           |
| **Step 6** | 탐색적 데이터 분석 (EDA)          | 분포 시각화, 상관관계, t-test 등                 |
| **Step 7** | 피처 선택/정제                  | 상관 높은 피처 추리기, 차원 축소 (PCA 등)            |
| **Step 8** | 모델 학습 및 평가                | Logistic Regression → XGBoost → BERT 등 |
| **Step 9** | 결과 해석                     | 어떤 피처가 가장 영향력 있는지 분석 (SHAP)            |

|데이터 타입|분석 기법 예시|
|---|---|
|시계열|시계열 분해, 계절성 분석, 이동 평균|
|범주형|교차표, 카이제곱, 그룹별 분포|
|수치형|평균/표준편차, 히스토그램, 회귀|
|텍스트|NLP 처리, 벡터화, 토픽 모델링|
|이미지|CNN 등 딥러닝 전용 처리 필요
