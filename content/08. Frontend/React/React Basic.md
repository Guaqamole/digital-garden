## State
- 리액트 컴포넌트의 상태임
	- 리액트 컴포넌트의 변경 가능한 데이터
	- 혹은 자바스크립트 객체라고 볼수있음
- state를 정의할때 중요한점: 꼭 렌더링이나 데이터 흐름에 사용되는 값만 state에 포함시켜야함
- 직접 변경불가
	- setState() 사용
