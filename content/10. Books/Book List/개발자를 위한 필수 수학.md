# Ch.1 기초 수학과 미적분
## Ch 1.4 함수
### 함수란
함수 function은 두개 이상의 변수 간의 관계를 정의
- x : 입력 변수 input variable / 도메인 변수 domain varaible / 독립 변수 independent variable 를 받아
- y : 출력 변수 output variable / 종속 변수 dependent variable 를 생성
함수는 변수간의 예측 가능한 관계를 모델링 (예 선형함수) 하기 때문에 유용

**중요: 독립 변수가 아무리 많아도 함수는 일반적으로 하나의 종속 변수만 출력합니다. 
여러 종속 변수를 계산할 때는 각 종속 변수에 별도의 함수를 사용합니다.**

### 실수를 다룰때
실수를 다룰때 중요한 특징은 무한한 개수의 x값과 y값을 갖는다.
따라서 $$ f(x) = 2x + 1 $$ 은 연속 함수 continous function 이며, 가능한 모든 x 값에 대한 y 값이 존재한다.

### 데카르트 좌표계
각 변수마다 직선이 그어져 있고, 두 직선이 교차되는 2차원 평면을 **데카르트 좌표계 Catesian coordinate system**, xy 평면 또는 **좌표 평면 coordinate plane** 이라고 한다.


## Ch 1.6 거듭제곱 (Exponentiation)
거듭제곱은 지정된 횟수만큼 숫자를 곱하는것.

$$ 2^3 = 2 * 2* 2 =8$$
- 밑 base: 거듭제곱하려는 변수 또는 값
- 지수 exponent: 밑을 곱하는 횟수
- 2^3 의 경우, 2가 base, 3이 exponent.
### 지수법칙
밑이 같을떄, 
- 거듭제곱을 곱할 때는 지수를 더한다.
- 거듭제곱을 나눌때는 지수를 마이너스한다.

$$ \frac{x^2}{x^5} = \frac{x * x}{x * x * x * x * x} = \frac{1}{x*x*x} = \frac{1}{x^3}=x^{-3}$$
- 거듭제곱의 거듭제곱일때는 지수의 곱셈이다.
$$ (8^3)^2  = 8^{3 \times 2} = 8^6$$
### 지수가 0일땐?
밑이 어떤 수든 지수가 0이면 결괏값이 1이되는 이유는 뭘까?

직관적으로 이해하는 가장 좋은 방법은 **어떤 숫자를 그 자체로 나눈값이 1이라고 생각하는것** 예시로, x^3 / x^3 이 1이라는것은 대수적으로 명백하다. 따라서 다음과 같이 표현할수있다.

$$ 1 = \frac{x^3}{x^3} = x^3*x^{-3} = x^{3+-3} = x^0 $$
a = b 이고, b = c 이면  a = c 라는 등식의 성질에 따라 x^0 = 1 이라는 것을 알 수 있다.


### 분수 지수
분수 지수는 제곱근가 같은 근 root 을 표현하는 다른 방법이다. 간단히 설명하면,
$$ \sqrt{ 4 } \ \ \text{는 '어떤 숫자를 거듭제곱하면 4가 될까요?' 라고 묻는것.} \implies 2$$
$$ 4^{\frac{1}{2}}=\sqrt{ 4} $$
세제곱근은 제곱근과 비슷하지만 스스로를 세번 곱해 결괏값이 되는 숫자를 구합니다. 8의 세제곱근은 ‘스스로를 세번 곱하면 8이 되는 숫자는 무엇인가요?’
여기서 세제곱근이 되는 숫자는 2 * 2 * 2 = 8 이므로 2이다.
$$ 8^{\frac{1}{3}}=\sqrt[3]{8}=2 $$

## 1.7 로그
**로그 logarithm 는 특정 수 와 밑이있을때 거듭제곱 횟수를 구하는 수학함수**
- 지진 측정부터 스테레오 음량관리까지 로그는 어디에나 존재한다.
- 머신러닝과 데이터 과학에도 많이 사용된다 (로지스틱 회귀의 핵심)

ex) 2를 몇번 거듭제곱하면 8이 될까요? (base를 몇번 x 하면 8 number 될까요?)
$$2^x = 8 $$
우리는 직관적으로 x = 3이라는것을알고있습니다. 하지만 이 수학연산을 좀더우아하게표현할 방법이 필요합니다. 
이것이 바로 `log()` 함수입니다. 로그로 x를 구하는 식을 표현하면 다음과같습니다.

$$ \log_{2}8 = x $$
로그는밑이2일때8이되는거듭제곱횟수를찾습니다. 일반적으로 지수함수를 로그로 표현하는공식은다음과같습니다
$$ a^x = b \text{  or  } \log_{n}b = x $$
```python
from math import log 

# 2를 거듭제곱해 8이 되는 지수는?
x = log(8, 2)

print(x) # 3.0
```

파이썬에서 `log()` 함수에 밑인수를 제공하지 않으면 일반적으로 기본밑이사용됩니다. 
지진측정과같은일부분야에서는로그의기본밑으로10을사용합니다. 
하지만데이터과학에서 로 그 의 기 본 밑 은 오 일 러 수, e 를 사 용 합 니 다 .

## 1.8 오일러 수(Euler’s Formula) 와 자연로그
1.8 오일러수와자연로그 수학에서오일러수라고부르는특별한숫자e를자주볼수있습니다. 
이것은파이와 비슷한 특수한숫자이며약 2.71828입니다. 
e를사용하면 수학적으로 여러문제를단순화할수있어 이를 많이사용합니다.****

> [!faq] 오일러 수가 많이 사용되는 이유
> **오일러수가 밑인 지수 함수의 도함수가 자기 자신이라는점이 오일러수의 특**성입니다. 이는 지수함수와 로그함수에 유용한속성이죠. 이장의뒷부분에서도함수에대해배우겠습니다. 
> 
> 밑 이 중 요 하 지 않 은 많 은 애 플리 케 이 션 에 서 는 가 장 간 단 한 도 함 수 를 만 드 는 오 일 러 수 를 선 택 합니다. 
> 이것이많은데이터과학함수에서오일러수를기본밑으로사용하는이유입니다

### 자연 로그 Natural Logarithm
e를 로그의 밑으로 사용할 때 이를 자연로그 라고 부른다. 폴랫폼에 따라 자연로그를 지정하는데 log() 대신 ln() 을 사용 할 수 있습니다. 따라서 e를 거듭제곱해 10이되는 지수를 찾는다는 의미의 자연로그를 $$\log_{e}10$$ 과 같이 표현하는대신, 줄여서 $$\ln(10)$$으로 표현합니다.
$$ \log_{e}10 = \ln(10)$$

## 1.10 미분 derivative
미분이란? **함수의 기울기를 나타내며, 함수의 어느지점에서 변화율을 측정하는데 유용.**
도함수란? 어떤 입력에 대한 함수의 순간 변화율 또는 그 지점에서 접선 (tangent line)의 기울기를 나타내는 함수를 말합니다.

> [!note] 왜 미분이 중요한가?
> 미분은 머신러닝과 기타 수학 알고리즘, 특히 경사 하강법 (gradient descent)에 사용된다. 기울기가 0이면, 출력 변수의 최솟값 또는 최댓값에 도달했음을 의미한다.
