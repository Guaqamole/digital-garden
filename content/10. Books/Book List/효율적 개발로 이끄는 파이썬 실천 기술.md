## 그 외 타입을 나타내는 개념
### mutable objects
가변 객체는 정의 후에도 그 값을 변경할 수 있다.
- list
- dict
- set

### immutable objects
정의후에 값을 변경 할 수 없음
- int
- float
- str
- tuple
- frozenset

### container objects
리스트나 딕셔너리 집합등 다른 객체에 대한 참조를 가진 객체
많은 컨테이너 객체는 이터러블 객체이므로 for 문에서 사용.
또한 내장함수 len을 이용해 길이를 얻거나
in, not in 연산자를 이용가능
#### sequence objects
컨테이너 객체중에서도 인덱스를 이용해 엘리먼트로 접근할 수 있는 객체를 시퀀스객체라고 부름
- str
- list
- tuple
#### mapping objects
인덱스가 아니라 딕셔너리와 같이 키를 잉요해 접근하는 객체
- dict

### iterable objects
iterator 라고 불리는 객체를 반환하는 던더 메서드 `__iter__()` 를 구현한 객체를 말한다.
for 문은 이 특수 메서드 `__iter__()` 를 호출해 이터레이터를 얻고, 그 이터레이터의 특수 메서드 `__next__()`를 호출해 엘리먼트를 하나씩 얻는다. 

컨테이너, 제너레이터 객체 모두 이터러블 객체이다.

### callable object
함수나 클래스 객체와 같이 () 를 붙여서 실행할 수 있는 객체를 가리킨다.
특수 메서드 `__call__()`을 구현한 클래스의 인스턴스 객체 역시 호출 가능 객체이다.

이 특성을 이용하면 함수든 클래스든 인스턴스든 동일하게 다룰 수 있다. 이처럼 타입보다 인터페이스를 이용하는 스타일을 duck typing 이라 부르며 파이썬에서 자주 쓰인다.

> [!note]  Duck Typing
> 타입을 미리 정하는게 아니라 실행이 되었을 때 해당 Method들을 확인하여 타입을 정한다.
> 
> 장점
> - 타입에 대해 매우 자유롭다.
> - 런타임 데이터를 기반으로 한 기능과 자료형을 창출하는 것
> 
>단점
> - 런타임 자료형 오류가 발생할 수 있다 런타임에서, 값은 예상치 못한 유형이 있을 수 있고, 그 자료형에 대한 무의미한 작업이 적용된다.
> - 이런 오류가 프로그래밍 실수 구문에서 오랜 시간 후에 발생할 수 있다
> - 데이터의 잘못된 자료형의 장소로 전달되는 구문은 작성하지 않아야 한다. 이것은 버그를 찾기 어려울 수도 있다

### Example Code
```python
class Parrot:
    def fly(self):
        print("Parrot flying")

class Airplane:
    def fly(self):
        print("Airplane flying")

class Whale:
    def swim(self):
        print("Whale swimming")

def lift_off(entity):
    entity.fly()

parrot = Parrot()
airplane = Airplane()
whale = Whale()

lift_off(parrot) # prints `Parrot flying`
lift_off(airplane) # prints `Airplane flying`
lift_off(whale) # Throws the error `'Whale' object has no attribute 'fly'`
```

# Ch.5 함수
## 함수는 객체
앞에서 설명한 것처럼 파이썬에서는 함수도 객체입니다. 함수를 정의하면 함수명의 이름
과 똑같은 함수 객체 function object가 만들어집니다. 함수 객체는 숫잣값이나 문자열과 같이
변수에 대입할 수 있습니다.

```python
def print_title(content = 'no content'):
    print(content)

print(type(print_title)) # <class 'function'>

f = print_title
print(f) # <function print_title at 0x000001F1FC6580D8>
```

함수 객체는 다른 함수의 인수나 반환값으로 사용할 수 있습니다.

```python
from typing import Callable

def print_page(content):
    print(content)

def print_title(printer: Callable[[str], None], title):
    print('@@@@@')
    printer(title.upper())
    print('@@@@@')

print_title(print_page, 'hello')

# @@@@@
# HELLO
# @@@@@
```

- `printer: Callable[[str], None]`
	- takes single arg `str`
	- return `None`

## Positional Argument (위치인수) vs Keyword Argument (키워드인수)
### Positional Argument
함수를 호출할 때 가인수 이름을 지정하지 않고 전달하는 실인수를 위치 인수positional
argument라고 부릅니다. 위치 인수를 사용할 때는 실인수의 순서가 가인수의 순서와 일치
합니다.

```python
def greet(name: str, age: int) -> None:
    print(f"Hello, {name}! You are {age} years old.")

greet(25, "Alice") # Incorrect order
```

```python
TypeError: greet() missing required positional argument 'name'
```

### Keyword Argument
함수를 호출할 때 가인수 이름을 지정해서 전달하는 실인수를 키워드 인수keyword argument
라고 합니다. 키워드 인수를 사용하면 호출 순서는 호출 결과에 영향을 주지 않습니다.

```python
def greet(name: str, age: int) -> None:
    print(f"Hello, {name}! You are {age} years old.")

# Using keyword arguments
greet(name="Alice", age=25)
greet(age=30, name="Bob")  # Order doesn't matter
```

```python
Hello, Alice! You are 25 years old.
Hello, Bob! You are 30 years old.
```

## 기본값의 함정
```python
from datetime import datetime

def log_message(message: str, timestamp: datetime = datetime.now()) -> None:
    print(f"{timestamp}: {message}")

# Calling the function multiple times
log_message("First message")
log_message("Second message")

# 2024-11-30 12:00:00: First message
# 2024-11-30 12:00:00: Second message
```

함수 정의가 실행될 때, 기본 매개변수 값은 왼쪽에서 오른쪽으로 값이 구해집니다. 이것은 표
현식이 함수가 정의될 때 한 번 값이 구해지고, 호출마다 같은 《마리 계산된 》 값이 사용된다는
것을 뜻합니다.

이것을 이해하는 것은 특히 기본값이 리스토나 딕셔너리와 같은 가변 객체일 때 중요합니다. 만약 함수가 그 객체를 수정하면 (가령, 리스트에 항목을 추가합니다)， 

그 결과 기본값이수정됩니다 이것은 일반적으로 의도하고 있는 것이 아닙니다 

→ **이 문제를 회피하는 방법은 기본 값으로 None을 사용하고, 함수 바디에서 명시적으로 검사하는 것입니다**.


## 길이가 변하는 위치인수 `*args` 
길이가 변하는 위치 인수를 받는 함수는 가인수 이름에 *를 붙여서 정의할 수 있습니다.
이 가인수 이름에는 임의의 이름을 이용할 수 있으나 관습적으로 `*args`를 자주 이용합
니다. `*args`는 가인수에 할당되지 않은 위치 인수를 튜플로 받습니다. `*args`를 지정할
수 있는 위치는 다른 위치 인수의 가장 마지막으로 기본값을 가지는 인수보다 앞입니다.

```python
def sum_numbers(*args: int) -> int:
    total = sum(args)
    return total

# Calling the function with different numbers of arguments
print(sum_numbers(1, 2, 3))          # Output: 6
print(sum_numbers(4, 5))             # Output: 9
print(sum_numbers(10, 20, 30, 40))   # Output: 100
```

## 길이가 변하는 키워드 인수 `**kwargs`  

길이가 변하는 키워드 인수를 받는 함수는 가인수 이름에 `**`를 붙여 정의할 수 있습니
다. 이 인수 이름에는 임의의 이름을 이용할 수 있으나 관습적으로 `**kwargs`를 자주
이용합니다. 

`**kwargs`는 가인수에 할당되지 않은 키워드 인수를 딕셔너리로 받습니다.
`**kwargs`를 지정할 수 있는 위치는 다른 위치 인수나 기본값을 가지는 인수보다 뒤, 죽
가장마지막입니다.

```python
def format_profile(**kwargs) -> None:
    for key, value in kwargs.items():
        print(f"{key.capitalize()}: {value}")

# Calling the function with different keyword arguments
format_profile(name="Alice", age=30, city="New York")

print("\n")  # For separation

format_profile(name="Bob", profession="Engineer", hobby="Cycling")
```

위치 인수와 키워드 인수를 길이가 변해도 받을 수 있도록 하면 어떤 인수의 호출에도
유연하게 대응할 수 있습니다.

## 키워드만 인수로 가지는 법 `*`
```python
def increment(page_num, last, *, ignore_error=False):
    next_page = page_num + 1
    if next_page <= last:
        return None
    raise ValueError('Invalid Arguments.')
    
>> increment(2, 2, ignore_error=True) # OK
>> increment(2, 2, True) # Error
```

## 위치만 인수로 가지는법 `/`
가인수 이름을 지정하면 에러가 발생하는 위치만 가지는 인수도 있습니다. 위치만 인수로
가지는 인수는 내장 함수 abs( ）나 내장 함수 pow() 등 일부 내장 함수에서 사용합니다.
```python
def add(x, y, /, z) :
	return x + y + z
	
add(l, 2, 3)

# z는 키워드로도 지정할 수 있음
add(l, 2, z=3)

# error
add(x=l, y=2, z=3)
```


## Unpack
### Using single `*`
```python
def print_page(a, b, c):
    print(a)
    print(b)
    print(c)

pages = ["one", "two", "three"]
print_page(*pages)
```

### Double `**` - keyword arguments
```python
def print_page(a, b, c):
    print(a)
    print(b)
    print(c)

pages = {"a": "hello", "b": "my name is", "c": "john."}
print_page(**pages)
```
